# Project Charter

## 项目名称

A-Share Quant Research Platform

## 项目使命

建立一个专业、可维护、可复现的 A 股量化研究与交易决策支持平台，用于研究假设验证、风险评估、回测比较、每日候选标的生成和报告输出。

## 核心原则

1. 风险控制优先于收益展示。
2. 真实可复现优先于漂亮但不可验证的回测曲线。
3. 数据来源、字段含义、更新时间、授权限制必须可追溯。
4. 所有信号必须可解释、可验证、可审计。
5. 严禁未来函数、数据泄漏、幸存者偏差和选择性汇报。
6. 不得承诺稳定盈利或保证收益。

## 项目目标

- 构建统一的工程目录、配置、文档和质量标准。
- 后续支持 A 股日线、复权、基本面、交易日历、停复牌、涨跌停、ST、退市和指数基准数据。
- 后续支持股票池、因子、信号、策略、组合、风控、回测、评估和报告模块。
- 后续支持每日研究报告，报告包含候选股票、参考区间、失效条件、止损止盈、仓位建议、卖出条件、风险提示和信号解释。

## 非目标

- 当前阶段不实现完整交易策略。
- 当前阶段不接入 Tushare 或 AkShare。
- 当前阶段不要求任何 API Token。
- 当前阶段不连接券商。
- 当前阶段不执行真实交易或模拟下单。
- 当前阶段不创建复杂前端。
- 平台不提供收益保证，也不替代投资者独立判断。

## 合规与风险声明

本平台输出仅为研究和决策支持材料，不构成投资建议。任何基于平台输出产生的交易决策均由使用者自行负责。回测收益、样本外收益、模拟盘收益均不代表未来收益。

## Phase 1 范围

- 检查并统一 Phase 0 文档。
- 建立 Python 3.11 与 uv 工程基础。
- 配置 ruff、pytest、mypy、pre-commit、GitHub Actions、Docker 和基础项目文件。
- 建立统一配置读取、统一日志系统和统一异常层级。
- 当前阶段仍不开发策略、不下载股票数据、不连接券商、不接入外部 API、不创建 Dashboard。
