# Definition of Done

## 通用完成标准

每个功能、策略、数据流程或文档变更完成前，必须满足以下条件：

- 需求和非目标已明确。
- 已检查现有实现，避免重复模块。
- 参数进入配置文件，禁止散落硬编码。
- 核心逻辑有测试。
- 相关测试已运行并记录结果。
- 文档已更新。
- 风险、限制和未解决问题已说明。
- 未删除不理解的代码。
- 未伪造数据、测试结果或实验结果。

## 数据功能完成标准

- 数据来源、字段含义、更新时间和授权限制已记录。
- 数据质量检查已实现或规划清楚。
- 可以复现实验使用的数据版本。
- 不存在已知未来函数或数据泄漏。

## 策略功能完成标准

- 策略假设和适用市场状态已说明。
- 样本内、样本外和滚动验证已完成。
- 与合适基准指数完成对比。
- 交易费用、滑点和冲击成本已纳入。
- 已考虑停牌、涨跌停、ST、退市、复权、分红送转和 T+1。
- 输出包含信号解释和风险提示。
- 不宣称稳定盈利或保证收益。

## 报告完成标准

每日报告必须至少包含：

- 数据日期。
- 信号生成时间。
- 最早可成交时间。
- 候选股票和筛选理由。
- 参考区间、失效条件、止损、止盈、仓位建议和卖出条件。
- 风险提示。
- 数据源说明。
