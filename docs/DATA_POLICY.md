# Data Policy

## 数据治理目标

所有数据必须可追溯、可复现、可校验。任何数据集进入研究和回测流程前，都必须记录来源、字段含义、更新时间、授权限制、清洗规则和质量检查结果。

## 数据源策略

- 首选数据源：Tushare（后续阶段接入）。
- 备用公开数据源：AkShare（后续阶段接入）。
- 本阶段不接入任何真实数据源，不要求任何 API Token。

## 元数据要求

每个数据表或数据文件必须记录：

- 数据源名称。
- 原始接口或下载地址。
- 字段名称和字段含义。
- 数据频率。
- 时区和交易日口径。
- 拉取时间和数据更新时间。
- 授权、许可和使用限制。
- 清洗、复权、对齐和过滤规则。

## 数据质量要求

必须检查：

- 缺失值和异常值。
- 重复记录。
- 交易日连续性。
- 股票代码变更和证券状态变化。
- 停复牌状态。
- 涨跌停状态。
- ST、退市和上市未满指定周期样本。
- 复权因子、分红送转和价格连续性。

## 防止数据泄漏

- 特征只能使用信号生成时间之前已经可获得的数据。
- 财务数据、公告数据和指数成分数据必须使用真实发布日期或生效日期。
- 回测不得使用回测结束后才知道的成分股、退市名单或幸存股票池。
- 必须区分信号生成时间、数据发布时间、数据入库时间和可交易时间。

## 敏感信息

- 不得将 API Key、Token、密码写入代码。
- 不得提交 `.env` 文件。
- 本地密钥只能通过环境变量或安全密钥管理工具读取。
